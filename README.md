TR Español Moderno - Latín Básico

Este es el hermano del proyecto inglés TR Modern English Latin-Free.

El español ES latín, así que no se puede quitar el latín 100%. Lo que hacemos aquí es quitar el latín fancy, abstracto, de iglesia y usar latín básico, simple, de cuerpo, más cerca del griego.

- No decimos genealogía, decimos lista de familia
- No decimos espíritu, decimos aliento
- No decimos virgen, decimos muchacha joven

Palabras simples que todos usan en casa. Fácil de leer, fácil de entender. Cerca del griego original.

Dominio Público. Gratis para todos.
